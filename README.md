# Luna Voyages

Next.js app for the Luna Voyages brand site and planning flow.

## Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Current page routes

- `/`
- `/robots.txt`
- `/plan/journey`
- `/plan/details`
- `/plan/contact`
- `/plan/thank-you`
- `/book-a-call`
- `/book-a-call/thank-you`
- `/real-honeymoons`
- `/design-brief`
- `/style-guide`
