# Luna Voyages (honeymoons.lk planner)

Next.js app for the Luna Voyages brand site and planning flow.

## Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Current page routes

- `/`
- `/robots.txt`
- `/start`
- `/plan/start`
- `/plan/consultation`
- `/plan/thanks`
- `/real-honeymoons`
- `/style-guide`

## Current API routes

- `/api/leads`
- `/api/map/flow-static`
- `/api/media/hero`
- `/api/media/image`

## Build

```bash
npm run build
```
