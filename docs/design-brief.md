# Luna Voyages — Website Design Brief (Designer Handoff)

## Purpose of This Brief
This is a **design brief for final visual design**, not a product spec and not a set of wireframes to be polished mechanically.

The current UI work should be treated as **high-definition wireframes**:
- structure is useful
- user flow logic is useful
- content hierarchy is useful
- form fields and step logic are useful
- layout rhythm is useful
- **visual design is not final**

The goal for design is to translate this into a website that feels emotionally elevated, brand-led, and unmistakably premium — **not a generic startup landing page, not a travel OTA, and not a “pretty Dribbble concept” disconnected from conversion and usability.**

---

## Design North Star
The website should feel like the **digital equivalent of arriving at a quiet luxury romantic resort** — calm, intimate, refined and intentional.

This is the core standard the design should be judged against.

When someone lands on the site, the feeling should be:
- slowed down
- emotionally drawn in
- reassured
- personally looked after
- inspired to begin a conversation

Not:
- rushed
- over-sold
- busy
- generic luxury
- SaaS-like
- travel marketplace-like

---

## What Luna Voyages Is
Luna Voyages is a **premium concierge-led romantic travel design brand** focused on Sri Lanka.

It designs journeys for:
- honeymoons
- babymoons
- anniversary escapes

This is **not** a booking site.
This is **not** an OTA.
This is **not** a hotel comparison experience.

The brand promise is:
**designed around the couple, handled personally, shaped with taste and care.**

The website’s job is to:
- create desire
- build trust
- communicate curation
- move the visitor into a planning conversation

Primary CTA:
**Start Planning**

## Core Strategic Principle
### The site sells the feeling and the curation, not inventory
Luna Voyages should **not** present itself like a place to browse and compare options.

The value is:
- taste
- curation
- shaping a journey
- removing noise
- designing something personal

### Why hotel lists are intentionally avoided
1. **Experience first**  
   Couples choose the type of journey before they choose the exact hotel.

2. **Curation is the value**  
   Hotel lists already exist elsewhere. Luna Voyages is valuable because it narrows and shapes choices with judgement.

3. **Every journey is custom**  
   The right stay depends on dates, pace, budget, priorities, and the occasion.

4. **Luxury removes noise**  
   A luxury brand should simplify, not overwhelm.

## Image Philosophy

This should not become a dense gallery or collage-heavy website.

# Website Structure

## 1. Homepage Hero
### Goal
Immediate emotional positioning plus a clear path into planning.

### Composition direction
- strong atmospheric hero image
- emotional positioning copy
- compact planning form embedded in the hero

This should feel premium and calm — **not** like a hard-sell lead-generation panel.

### Important product logic
The hero form is **not redundant** with the planning funnel.
It supports a specific entry journey.

There are **two valid user journeys** into planning:

#### User Journey 1 — Hero-first entry
- user starts from the homepage hero form
- after submitting that form, they move into **Step 2** of the planning flow
- this path is useful for users coming from targeted entry points such as paid traffic / campaign landing scenarios

#### User Journey 2 — CTA-first entry
- user clicks **Start Planning** from the homepage or other CTA locations
- they begin at **/plan/journey**
- this is the full Step 1 entry path

This dual-entry system is intentional.
It allows campaign and channel flexibility, including paid traffic and UTM-based routing.

### Design implication
The designer should make the homepage hero form feel like:
- a refined concierge opening move
- simple and inviting
- visually integrated with the hero

It should **not** look like a duplicate of the full planning stepper.
It should feel like a lighter, elegant front door into the same system.

# Planning Funnel Structure

## Primary funnel routes
- `/plan/journey`
- `/plan/details`
- `/plan/contact`
- `/plan/thank-you`

### Funnel behaviour
- reduced header/footer chrome compared with the homepage
- premium, editorially styled progress tracker on journey/details/contact
- no progress tracker on thank-you
- strong continuity with the homepage visual language

### Important guidance for the designer
The current product implementation gets the **functionality** mostly right.
The final design should elevate the feeling so the funnel still belongs to the same brand world as the homepage.

The target is not a generic multi-step form.
The target is a **quiet luxury planning experience**.

---

## Step 1 — `/plan/journey`
This is the fuller preference-capture entry point for users who start from **Start Planning** rather than the hero form.

It captures things like:
- travel timing
- trip length
- experience direction
- standout moments
- desired pace

### Design goal
Make this feel:
- inviting
- elegant
- simple
- emotionally guided

Not like a questionnaire dashboard.

---

## Step 2 — `/plan/details`
This captures comfort level, occasion, and personal notes.

### Design goal
This step should feel:
- considered
- personalised
- progressively tailored

A summary of earlier preferences is helpful and should feel curated rather than technical.

---

## Step 3 — `/plan/contact`
This captures contact details and allows final review before submission.

### Design goal
This is where many form flows become generic.
The design should resist that.

It should still feel:
- warm
- premium
- calm
- personal

A review panel is useful, but should be visually integrated into the brand language.

---

## Thank You — `/plan/thank-you`
The confirmation page should not feel like a dead end.

It should:
- reassure the user
- confirm that the request is being reviewed personally
- summarise what was submitted
- explain what happens next
- keep the tone human and high-touch

---

# Book a Call Flow

## Routes
- `/book-a-call`
- `/book-a-call/thank-you`

## Purpose
This is a separate, lower-friction path for people who prefer a short conversation first.

It should feel:
- personal
- calm
- reassuring
- distinctly non-salesy

But it still needs to convert clearly.

## Design direction
- premium editorial intro
- single strong image
- concise “what to expect” guidance
- short, elegant call request form
- dedicated confirmation page

## Relationship to the planning flow
The two paths should feel connected but distinct:
- planning path = more preference-led
- call path = more conversation-led

Cross-links between the two are intentional and should feel natural, not pushy.

---

# UI Component Direction
The site is implemented using **shadcn/ui-compatible components**, but the final design should not look like default component library output.

Components should feel:
- restrained
- premium
- architectural
- tactile
- editorial

Avoid anything that reads as:
- SaaS admin UI
- startup landing page blocks
- template marketing site

Buttons, cards, forms, progress indicators, and inputs should feel custom-curated even if they are built on standard primitives.

---

# What The Designer Should Avoid
Avoid visual patterns associated with:
- Booking.com
- Expedia
- TripAdvisor
- generic luxury agency landing pages
- trendy Dribbble travel concepts that ignore real content and conversion

Specifically avoid:
- hotel comparison layouts
- price grids
- ratings and review widgets
- search/filter-heavy interfaces
- loud testimonial carousels
- excessive glassmorphism / gradients / trendy UI tricks
- over-designed editorial layouts that hurt clarity
- dark moody luxury styling that fights with mixed hotel imagery

---

# What Success Looks Like
When the right couple lands on the site, they should feel:

**“This is exactly the kind of journey we want — and these people will handle it beautifully.”**

The final design should create three outcomes at once:
- emotional desire
- trust in taste
- confidence to start the conversation

If the work is only beautiful but not usable, it fails.
If it is only functional but not emotionally transporting, it fails.
If it feels like a generic luxury travel website, it fails.
